Settings

Each question is a saved lookup. When you open the popup or side panel, every question whose site pattern matches the current URL is run against the full page, and anything that wasn't there last time is flagged NEW. No AI is involved — it's exact keyword, pattern and regex matching on the page text.

What counts as dealt with

Reinstalling an extension makes Chrome delete everything it stored, including the record of what you had marked Done — which is why the same cards kept coming back. So Done now also marks that mention read in Trello. Trello remembers it, this extension does not have to, and the Trello bell agrees with the panel.

"Today", "Due tomorrow" and every date shown are worked out in this timezone. It matters if you are not sitting where the firm is: at midnight in Karachi it is still early afternoon of the previous day in Dallas, so with the computer's own timezone "Today" empties out while the firm is still working, and a card due 6 August reads as the 7th. Central handles its own switch to daylight time.

Leave this on and your Done list survives reinstalling. The trade-off: Trello also marks things read when you open its notification bell, so a mention you glanced at there — but never dealt with — will not appear as new. It is never hidden silently: the panel says "3 mentions were already read in Trello — show them", and Show older always lists everything. Turn this off and only this extension's own record counts, which means the Done list is lost whenever you reinstall.

Sort mentions into Needs me / Waiting / FYI

Off by default, and nothing depends on it. With a Google AI Studio key, each mention gets a label — Needs me when someone is asking you to do something or answer a question, Waiting when the work sits with somebody else, FYI when it is just an update. "Needs me" sorts to the top.

It only labels and reorders. Nothing is ever removed from your list, so a wrong label costs you a glance rather than a missed deadline. If the key is absent, rejected or Google is down, your queue is exactly what it is today.

Slack (experimental)

Reads an open Slack tab — a DM, or an @mention in a channel — and files anything that reads as a real task onto its own Slack board, using the same key and judgment as Sort mentions above. It never opens a Slack tab itself, never posts anything, and only ever reads text that's newly appeared since the last check.

New and unverified against your actual Slack. Unlike the rest of this extension, this hasn't been tested against a real, live Slack page — it may miss things, or need a fix once you try it. Off by default; turn it on and tell me what happens.

Desktop notifications

When someone tags you in a Trello comment, a notification pops up on your desktop within a second or two. Click it to jump straight to that card — it's marked done at the same time. Done clears it without opening anything.

This works by watching Trello's own notification bell in an open Trello tab, so keep a Trello tab open — pinning it is ideal. With no Trello tab open there's nothing to read, and you'll get the tags when you next open Trello. If nothing appears at all, check that Chrome itself is allowed to send notifications in your system settings.

Mobile notifications

Relays the same tag, follow-up and "more waiting" notifications to your phone over Web Push, via a small server you run yourself (see mobile-push/ in the repo). Pair your phone once at that server's address — open it on your phone, add it to your Home Screen, and it will show you an 8-character pairing code — then paste the server address and that code below.

Ask Claude
